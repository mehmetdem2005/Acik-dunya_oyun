4. KNOWN REMAINING ISSUES (HONEST)
----------------------------------
- LOD3 (billboard impostor) not implemented — for ultra-far distance need
  baked image-card replacement. Current LOD2 (5.7k tri) is sufficient for
  most mid-far cases.
- Apple stems and apple body share M_Apple material (vcolor only differs;
  could split for separate material if engine needs it).
- Wind animation NOT implemented — vertex shader sway needs UV2 or attribute
  weights for trunk vs twig motion frequency.
- Atlas is placeholder procedural (9 variants from Python-baked silhouettes).
  Real photo atlas would improve realism but requires user input.
- Contact sheet has minor cell-size mismatch (close-up rendered at different
  zoom). Cosmetic only.
- Collision proxy is single cylinder — does not include canopy collision
  (intentional, leaves should be walk-through).
