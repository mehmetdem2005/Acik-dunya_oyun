# Dragon Production Asset

This directory is generated by `.github/workflows/build_dragon_asset.yml` from the modular Blender production code in `tools/dragon_production/`.

Generated deliverables:

- `dragon_master.blend`
- `dragon_master.glb`
- `dragon_master.gltf` + `dragon_master.bin`
- PBR texture sets under `textures/`
- three review renders under `previews/`
- `dragon_asset_manifest.json`
- `dragon_qa_report.json`
- `dragon_qa_reopen_report.json`

Godot integration uses `dragon_character.tscn`. Gameplay code must use the wrapper scene rather than modifying the imported glTF scene directly.

The build is rejected when required nodes, UV sets, skin weights, collision proxies, materials, LOD order or any of the twenty named animation actions are missing.
